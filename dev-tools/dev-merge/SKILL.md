---
name: dev-merge
description: Guides on how to merge code incrementally and safely, especially for PR stacks
---

At the end of a dev cycle, we want to merge code into main. Usually we will have a stack of PRs.

Polish each PR from the bottom up, so they become ready. This is a collaborative process where you will do fixes until I merge the PR, then we move on to the next PR in the stack. If there are changes in direction, we will record those to align other PRs as we merge one by one.
