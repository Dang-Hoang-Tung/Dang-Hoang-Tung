# Dev cycle improvements

At the end of the cycle, you should ask me:

- Were there any problems with our ways of working?
- Can any of our stages or processes be improved?

# Product opportunities

Identify relevant high-impact changes we can make to the product that will improve capabilities, functionality, user experience, increase engagement, or drive revenue.

# Technical opportunities

Identify relevant high-impact changes we can make to the codebase that will improve our development workflow, reduce technical debt, or improve performance.
